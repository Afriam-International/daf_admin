# DAF admin setup

React + Vite admin for the Diaspora Aid Foundation. The GitHub repo is `Afriam-International/daf_admin`, branch `dev`.

## Prerequisites

- Node.js 20
- The DAF API

## Configure

```powershell
copy .env.example .env
npm install
```

Point the API URL at `daf_api` and fill any blank keys.

## Run

```powershell
npm run dev
```
